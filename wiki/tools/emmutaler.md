# emmutaler

*Fuzzer for Apple's iBoot second-stage bootloader.*

| | |
|---|---|
| Category | Dynamic analysis, fuzzing and rehosting |
| Consumes | binary |
| Status | `needs-hardware` |
| Upstream | https://github.com/galli-leo/emmutaler |
| Language | Go |

## What it does

Fuzz Apple's iBoot second-stage bootloader.

## What it applies to

Apple iBoot only.

## Running it

No runner is provided. Needs decrypted Apple iBoot images, which are not distributable.
