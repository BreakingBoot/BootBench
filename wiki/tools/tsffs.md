# tsffs

*Simics-based fuzzer targeting firmware and UEFI boot paths.*

| | |
|---|---|
| Category | Dynamic analysis, fuzzing and rehosting |
| Consumes | source |
| Status | `needs-license` |
| Upstream | https://github.com/intel/tsffs |
| Language | Rust |

## What it does

Fuzz firmware inside a Simics full-system simulation.

## What it applies to

Anything Simics can simulate, including UEFI and embedded bootloaders.

## Running it

No runner is provided. Requires Intel Simics, which is not freely redistributable.
