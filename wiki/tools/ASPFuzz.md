# ASPFuzz

*Fuzzer for the AMD Secure Processor on-chip bootloader.*

| | |
|---|---|
| Category | Dynamic analysis, fuzzing and rehosting |
| Consumes | binary |
| Status | `needs-hardware` |
| Upstream | https://github.com/TeumessianFox/ASPFuzz |

## What it does

Fuzz the AMD ASP on-chip bootloader.

## What it applies to

The AMD Secure Processor on-chip bootloader only.

## Running it

No runner is provided. Targets the AMD Secure Processor ROM on specific silicon.
